# claude-mods

Personal Claude Code mods, served as a plugin marketplace.

## Install

```
/plugin marketplace add bodypas/claude-mods
/plugin install usage-live@bodypas-mods
```

## Plugins

- `usage-live`: one line under the prompt with the context fill, the 5-hour and weekly limits, and the session cost. Each bar changes from green at 0% to red at 100%.
